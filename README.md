Codebase for connecting the WANDR model with unity. The mouseclick done in unity will be send to the WANDR model through a TCP server. WANDR then calculates a movement from the start coordinates to the mouseclick (goal) coordinates.


Works on the following versions, also on some older Unity version. Newer version are not tested. 
Unity Version: 6000.5.6f1 https://unity.com/releases/editor/whats-new/6000.5.6f1#installers
WANDR model: https://github.com/markos-diomataris/wandr
Linux: Ubuntu 22.04.5 LTS
